# ACR Marketplace

Verified plugin, skill, and MCP server discovery with ANS trust anchoring.

## Tools

| Tool | Purpose |
|------|---------|
| `search` | Search skills, plugins, and MCP servers across federated registries |
| `browse` | Browse resources by category, type, or popularity |
| `sources` | Inspect registry source status and counts |
| `verify_plugin_trust` | Verify publisher ANS identity and ACR audit chain anchor (`127.0.0.1:20443`) |
| `publish_plugin` | Publish an ANS-anchored plugin to the federated ACR marketplace |
